{# Inline identity helpers, imported "with context" so they read the per-request `avatars` map without threading it through every call: import "_ident.html" as idm with context (in {%% %%} tags) idm.who(name) -- manager team portrait + name idm.headshot(pid, link=False) -- a player's Sleeper headshot (bare img) idm.posrank(pid) -- that player's position rank THIS WEEK idm.player_link(pid, name) -- a player's name, linked to /player/ All best-effort and degrade cleanly: `who` shows the portrait only when a manager avatar exists for that name (else just the name); a headshot that 404s removes itself via onerror; `posrank` renders nothing if `week_pos_ranks` isn't in context (only the weekly report supplies it) or has no entry for this player. `headshot`/`player_link` link to the player-profile page only when a Sleeper `pid` is known -- a caller without one (a name-only row, or a compare row that never resolved a sleeper_id) falls back to plain unlinked text/image, never a link to a page that would 404. `league`/`season`, when present in the calling template's own context, ride along as query params for continuity (which league/season the click came from); a page with neither (the league-agnostic NFL Stats tab) still links, just without that context. No nested Jinja comments here -- they don't nest. #} {# `is string` guards are deliberate: pandas NaN is truthy in Jinja, so a raw record (not run through records()) would otherwise render "nan" / a dead img. #} {% macro who(name) -%} {%- set nm = name if name is string else None -%} {%- set url = avatars.get(nm) if (nm and avatars) else None -%} {% if url %}{% endif %}{{ nm or "N/A" }} {%- endmacro %} {% macro _player_url(pid) -%} /player/{{ pid }}{% if league %}?league={{ league }}{% if season %}&season={{ season }}{% endif %}{% elif season %}?season={{ season }}{% endif %} {%- endmacro %} {% macro headshot(pid, link=False) -%} {%- if pid is string and pid %} {%- if link %}{% endif -%} {%- if link %}{% endif -%} {% endif -%} {%- endmacro %} {% macro player_link(pid, name) -%} {%- if pid is string and pid %}{{ name }}{% else %}{{ name }}{% endif -%} {%- endmacro %} {% macro posrank(pid) -%} {%- if week_pos_ranks and pid in week_pos_ranks -%} {%- set pr = week_pos_ranks[pid] -%} {{ pr.position }} #{{ pr.rank }} {%- endif -%} {%- endmacro %}
