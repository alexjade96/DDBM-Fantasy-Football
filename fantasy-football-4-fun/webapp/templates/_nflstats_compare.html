NFL Stats: the underlying numbers

Straight from nflverse’s own public data releases — the same files the R nflreadr and Python nflreadpy packages read. No league required. The player leaderboard carries the usage rates a fantasy points total hides: target share, air-yards share, WOPR, RACR / PACR. The schedule view is real game results with the closing line, roof, surface and rest days. Sort by any column.

{# hx-trigger is submit only (NOT change) -- the dropdowns just stage a selection; the table reloads when Load is clicked. Only View / Season / Source (and Position on the leaderboard view) change the underlying dataset the server assembles -- see the note above `data-nfl-clientfilter` below for why Position/Team/Week are handled differently per view. #}
{# Each secondary control matters to some views only; it still stays in the DOM and posts, the script just dims it where it's ignored. Source -> player leaderboard; Position -> leaderboard + comparison; Team -> all three views; Week -> schedule. #} {# Position changes the leaderboard's own COLUMN SET (QB vs skill stats) and its rank numbering (server re-ranks within the filtered set), so it stays a server reload on the "players" view. On "compare" the column set and rank are position-independent -- pure row filtering -- so it is fetched once at pos=ALL and filtered client-side there instead; `data-nfl-clientfilter="compare"` marks that. #} {# Team has the same rank-renumbering issue as Position on the leaderboard (the server re-ranks 1..N within one team), so it stays a server reload there too. On schedule/compare, filtering by team doesn't change the column set or any ranking, so both fetch once at team=ALL and filter client-side; `data-nfl-clientfilter` lists which views do that. #} {# Week never changes the schedule table's columns or a rank, so it is always a client-side filter there: fetch the whole season (week=ALL) once and filter rows in the browser as the control changes. #} {# Right-justified on the controls line (margin-left:auto). A real submit button -- the form's hx-trigger="submit" is what reloads #nfl-board. #}
