Gems & busts

Ranked by value against draft position, not raw points — so a late flier that returned nothing sits near zero, while an early pick that returned nothing sinks. +/− is how many places the pick beat (or missed) where it was taken. Value counts only points started for the drafting team; where a bust went on to score for somebody else, that is noted beside him — the difference between a bad player and a bad decision.
