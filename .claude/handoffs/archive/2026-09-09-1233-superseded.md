## Architecture

### `sleepermetrics/nflstats.py` (webapp-only, NOT parity-diffed)

- `SOURCE = "sleeper"` -- every row carries `source == SOURCE`.
- `_USAGE_KEYS` -- the ~27-key subset pulled from the ~85-key Sleeper line
  (`off_snp`/`tm_off_snp`, `rec`/`rec_tgt`/`rec_yd`/`rec_air_yd`/`rec_rz_tgt`,
  `rush_*`, `pass_*`, `pts_ppr`/`pts_std`/`pts_half_ppr`).
- `raw_week(season, week, reload=False)` -> `{player_id: {usage-key: value}}`.
  Snapshot-first: in-proc `_week_cache` -> `season/stats/<season>/<week>.json`
  -> live `scoring.nfl_stats`. Trims to fantasy positions, drops the
  metadata-only never-played stub (same guard as `metrics._position_totals`).
  Degrades to `{}`.
- `player_usage(s, weeks=None, reload=False)` -- **Season-scoped**. Per player
  over the window: `snap_share`, `targets`, `tgt_share` (denominator = that
  player's NFL team's targets those same weeks, from `players()`), `rz_touches`,
  `air_yards`, `adot`, `ppg_ppr`. Cached per `(league_id, season, weeks)`.
  Ready for a Roster/Draft usage column; NO tab consumes it yet.
- `player_leaderboard(season, pos="ALL", weeks=None, limit=200, reload=False)`
  -- **league-free** (no `Season`; walks `raw_week` for weeks 1..18).
  Season totals per player joined to `players()` for name/pos/team/**`gsis_id`**,
  ranked by `pts_ppr`, with volume totals + `snap_share`/`tgt_share`/
  `rz_touches`/`adot`. Backs the NFL Stats tab's Sleeper source + `compare_sources`.
  **`_lb_cache` key is `(season, pos, weeks)` -- NOT `limit`.** The full ranked
  board is cached; `.head(limit)` applied on return. (A `limit`-keyed cache bit
  once: a `limit=8` result was reused for `limit=60`.)
- `clear_cache()` -- clears `_week_cache` / `_usage_cache` / `_lb_cache`;
  mirrors `scoring.clear_stats_cache()` for the live-rescore path.
- Storage: NEW `season/stats/<season>/<week>.json` tree, sibling of
  `season/adp/`, same `SLEEPERMETRICS_SEASON_DIR` root.

### `python/nflref/` (webapp-only, OUTSIDE sleepermetrics, mirrors ffadp)

- `base.py` -- `NflDataset` ABC (`name`/`label`/`EARLIEST`/`_asset(season)`/
  optional `_tidy(df)`/`fetch(season, reload=False)`). Shared snapshot
  round-trip + EARLIEST guard + degrade-to-empty-frame all in `fetch()`.
  `DATASETS` = `{d.name: d for d in (PlayerStats(), Schedules())}`.
- `board.py` -- `load(dataset, season, reload=False)` public dispatch on
  `DATASETS`. Empty frame for unknown key / unresolved fetch; never raises.
- `api.py` -- `read_release_parquet(asset)` ->
  `https://github.com/nflverse/nflverse-data/releases/download/<asset>`,
  `pd.read_parquet(BytesIO(...))`. The one monkeypatchable outbound call.
- `cache.py` -- per-`(dataset, season)` **parquet** snapshot under
  `season/nflverse/<dataset>/<year>.parquet`. `_NFLVERSE_DIR` is the
  monkeypatch point in tests.
- `player_stats.py` -- `PlayerStats`, asset `player_stats/player_stats_<year>.parquet`,
  `EARLIEST = 2016`. `_tidy` keeps `_KEEP` cols (identity + volume +
  `target_share`/`air_yards_share`/`wopr`/`racr`/`pacr`) and filters
  `season_type == "REG"`.
- `schedules.py` -- `Schedules`, asset **`schedules/games.parquet`** (ONE
  all-seasons file -- NOT `schedules.parquet`; that 404s), `EARLIEST = 1999`.
  `fetch` is fully overridden (not `super().fetch`) to slice to the season
  BEFORE snapshotting so each `<year>.parquet` holds just that year.
- `summary.py` -- the webapp tab's presentation views:
  - `POSITIONS = ("ALL","QB","RB","WR","TE")`, `SOURCES = ("nflverse","sleeper")`
  - `player_leaderboard(season, pos, source="nflverse", limit=200, reload=False)`
    -- `"nflverse"` aggregates the weekly `player_stats` frame (sum for counts,
    mean for `*_share`/WOPR/RACR/PACR, ranked by `fantasy_points_ppr`);
    `"sleeper"` delegates to `sleepermetrics.nflstats.player_leaderboard`.
  - `leaderboard_columns(pos, source)` -- `_NFLVERSE_QB_COLS` / `_NFLVERSE_SKILL_COLS`
    vs `_SLEEPER_QB_COLS` / `_SLEEPER_SKILL_COLS`. Sleeper set swaps
    WOPR/RACR/air-share for snap-share/aDOT/RZ-touches.
  - `compare_sources(season, pos="ALL", limit=200, reload=False)` -- loads both
    leaderboards, joins on **normalised name + position** (`_norm_name`, mirrors
    `ffadp.identity._norm`). For each stat in `_COMPARE_STATS` (games / targets /
    receptions / rec+rush+pass yds+TD / PPR pts) emits `<key>_sleeper`,
    `<key>_nflverse`, `<key>_delta` (SL minus NV), only rows that differ,
    biggest `total_abs_delta` first, + a `summary` dict (`matched` /
    `in_agreement` / `differing` / `sleeper_only` / `nflverse_only`).
    Coerces NaN team -> None inside the loop.
  - `schedule_grid(season, week=None)` / `schedule_weeks(season)`.
- `__init__.py` exports `load`, `NflDataset`, `DATASETS`, `summary`,
  `player_leaderboard`, `leaderboard_columns`, `compare_sources`,
  `schedule_grid`, `schedule_weeks`.

## Important Discoveries

- **Sleeper's `/stats/nfl/regular/<season>/<week>` line is rich.** ~85 keys
  incl. `off_snp`/`tm_off_snp` (snap share), `rec_tgt`, `rec_air_yd` (aDOT),
