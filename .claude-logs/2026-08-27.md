## Bug fix: league chain broke on `previous_league_id == "0"`

Reported: picking a league from the user-lookup list (`1180315472216506368`,
"Coin Flip and FF") errored with "Couldn't load league ...".

Cause: Sleeper ends a season chain with `previous_league_id` set to either
`null` OR the string `"0"`, league-dependent. This league's 2024 season link
carried `"0"`. Every `league_chain` walker guarded only against
null/empty/"None", so `"0"` passed the loop guard and it issued
`GET /league/0` -> 404 -> the whole `seasons()` call threw, and the webapp
surfaced it as the generic load error.

Fix: add `id != "0"` to the while-loop guard in all four chain walkers
(cross-language, since the R and Python builders are mirrored):
- `python/sleepermetrics/league.py` `league_chain()`
- `R/sleepermetrics/R/league.R` `sl_league_chain()`
- `ddbmFF.R` `buildLeagueChain()`
- `leagueAnalytics.R` `buildLeagueChain()`

Verified (Python): `league_chain('1180315472216506368')` now returns
`['2024','2025']`, `seasons()` loads both (12 teams each), and the webapp
`pick()` + overview tab render clean. `pytest`: 71 passed. R suite not run
(Rscript not on PATH here); the R edit is the identical one-token guard.

## Bye inference for stock Sleeper brackets (`sleeper_bracket`)

Reported question: does the bye logic compute for non-custom (normal Sleeper)
brackets, e.g. Coin Flip and FF / other 6-8 team leagues?

Finding: it did NOT. Sleeper's `winners_bracket` has no bye node. A
first-round-bye team (seeds 1-2 in a 6- or 8-team bracket) simply isn't
listed until the round it enters, where its slot is a raw roster id with no
`t1_from`/`t2_from` ref. `sleeper_bracket()` built matchups only from actual
`wb` game rows, so the bye teams appeared floating in Round 2 with no Round 1
card, no `BYE` result row, no amber bye connector on the bracket chart, and
`game_log`'s new `_bye_blurb`/`_seed_ranges` machinery stayed inert
(`byes: []`, `blurb: None`). Verified broken on Coin Flip and FF 2025,
Liberty Boys 2025, and DDBM's OWN 2022 & 2023 Sleeper brackets (4-team 2024
correctly has no byes; the incoherent custom 2025 wb has all-games R1 and is
superseded by the committed config anyway).

Fix (Python-webapp-only; `playoffs.py`):
- `_sleeper_byes(wb, name_of, seed_map)` -- pure inference. Primary signal:
  a raw-int slot with no `_from` ref, first seen in round r >= 2, for a team
  absent from every earlier round -> idle rounds 1..r-1. Consolation `L:`
  re-entrants always carry a `_from` ref so they're excluded. Fallback (a
  malformed bracket with NO `_from` refs anywhere): seeded playoff field
  minus round-1 participants, ordered by seed.
- `_sleeper_seed_map(league_id, season, playoff_start)` -- builds
  `{seed: team}` from `seeds(s, through_week=playoff_start-1)` (regular-season
  seeding, the same rule `playoff_summary` documents). Stored on the config as
  `_seeds`, which also populates the previously-blank `seed` column in
  `playoff_summary` and the `#N` badges on the bracket chart.
- `sleeper_bracket()` materialises the inferred byes as `{"bye": team}`
  matchups (`R{r}B{n}` ids) in each sat-out round, so the engine's existing
  BYE path, the chart's amber dotted connectors, and the Games-log blurbs all
  light up unchanged.

Verified: bye cards + amber connectors now render for Coin Flip / Liberty /
DDBM 2023 (rendered to scratchpad PNGs); `game_log` R1 reads "Seeds 1-2 on a
bye." with both teams listed; champions unchanged across all six brackets;
`playoff_summary` seed column populated, `games` count still excludes BYE
rows; `scope_frame` title/consolation/all splits sane; webapp `pick()` +
`/chart/bracket` clean. 5 new unit tests for `_sleeper_byes` (raw-id
detection, ignores R1 players, ignores consolation re-entrants, none when all
play R1, presumption fallback). `pytest`: 76 passed (was 71). Parity
unaffected -- `sleeper_bracket()` has no R counterpart and the parity harness
reads committed disk configs, not this generator.

## Toilet bowl drawn from Sleeper's real losers_bracket (a proper tree)

The toilet-bowl chart looked "unstructured/messy" because it was drawing a
bracket-shaped figure from data that had no bracket in it: `toilet_bowl()`
reads FLAT weekly Sleeper matchups and, without advancement links, a losing
team just reappears next week against someone else -- so bracket-style
"winner advances" connectors always crossed and misled. Root cause:
**Sleeper stores a proper `/league/<id>/losers_bracket`** (Coin Flip and FF
2025: a 7-node consolation tree with `t1_from`/`t2_from` refs, round-1 byes,
and placement games) that the code never read.

- `playoffs.py`: new **`sleeper_losers_bracket(league_id, season)`** -- the
  counterpart to `sleeper_bracket()`. Reads `/losers_bracket` (same node
  shape as the winners bracket), resolves it round by round with
  `_sleeper_side` (W:/L: refs) and `_sleeper_byes` (a raw roster id first
  seen in round r>=2 with no `_from` ref = a bye), materialises byes as
  `{"bye": team}` matchups, sets `final` to the `p == 1` game and
  `_placements` from the other `p` values. Returns `None` (caller falls
  back) when there's no coherent losers bracket. Cached in `_gen_cache`.
  Exported from `__init__.py`.
- `plots.py`: `plot_playoff_bracket` gains a `variant` arg
  (`"championship"` default / `"consolation"`). The consolation variant only
  changes the title ("<league> · <season> Consolation Bracket: Last place,
  X") and the caption ("Best consolation finish: X · Last place: Y"; last
  place = loser of the `p == 1` game if `toilet` didn't name one); the whole
  layout / card / connector engine is shared, so the two brackets look
  identical.
- `plots.py`: `plot_toilet_bowl(p, toilet, ref_scores, losers_bracket=None)`
  -- when `losers_bracket` is a resolved `Playoff` (from
  `sm.playoff(sm.sleeper_losers_bracket(...))`), it **delegates to
  `plot_playoff_bracket(..., variant="consolation")`**: a real
  left-to-right tree, clean non-crossing connectors, byes as amber cards,
  placement games muted + tagged. The old flat week-column code (games +
  amber bye cards, centred columns) is kept verbatim as the FALLBACK for a
  league with no losers bracket.
