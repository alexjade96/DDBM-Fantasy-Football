# 2026-08-01 — Draft tab: grades chart, tabbed gems/busts/undrafted, position-adjusted grade

Repo: `DDBM-Fantasy-Football` (branch `main`). Continuation of the same Draft-tab
refinement thread as the prior commit `637a0f9`.

## Requests handled
1. "reconsider the draft grades metric, remove the bar chart version & order the
   grade vs value graphic by bottom bar/roster points instead of value (to
   illustrate perceived loss)"
2. "pull together gems/busts/undrafted into single section split by tabbing to
   view, and add position-adjusted grade as well"
3. Clarifying question asked via AskUserQuestion (placement + baseline for the
   position-adjusted grade) — user answered: it's a ranking *variant* for
   gems/busts (not a manager-level chart), baseline = startable-pool average.

## Changes made
- `python/sleepermetrics/plots.py`: deleted `plot_draft_grades` (bar chart).
  `plot_draft_grades_value` (dumbbell) now sorts by `points` (roster points
  kept) instead of `total`, so row order traces perceived loss top-to-bottom.
- `python/sleepermetrics/draft.py`: added `_startable_pool_avg()` — per-position
  average true-season points among the top N leaguewide players, N sized to
  this league's actual starting slots (fixed + FLEX share) x team count.
  `draft_board()` gains `pos_avg`/`pos_adj`/`adj_rank`/`adj_steal` columns.
  `draft_extremes()` now also returns `adj_gems`/`adj_busts` ranked on
  `adj_steal`.
- `python/webapp/app.py`: removed `draft_grades` from `SEASON_CHARTS`/
  `CHART_META`; draft tab's `charts` list trimmed to
  `["draft_grades_value", "draft_value"]`.
- `python/webapp/templates/tab_draft.html`: merged the Gems / Busts /
  Undrafted sections (previously three always-visible blocks) into one
  "Draft finds" section with a native radio-driven tab switch (no JS),
  reusing the existing `.viewswitch`/`vs-radio`/`vs-panel` idiom from
  `_week_fa.html`. Added a 4th tab, "Position-adjusted", showing the same
  gems/busts pairing ranked by `pos_adj`/`adj_steal`.
- `python/webapp/static/style.css`: added `.gb-vs-mode` tab-switch rules
  (mirrors the existing `.fa-vs-mode` pattern).
