# 2026-08-04 — Roster tab rebuild, Players of the Week, and merge with Coaching into "Management"

Repo: `DDBM-Fantasy-Football` (branch `main`). Long iterative session, driven by
successive small requests each verified against live 2025/2024/2023/2022 data
(league `1252770181306929152`) before moving to the next, plus one exploratory
discussion (unify Coaching & Roster?) that was revisited and reversed later in
the session once the user decided to actually do it.

## Requests handled (roughly in order)

1. Exploratory question: whether to unify Coaching & Roster tabs — recommended
   keeping separate at the time (different questions: composition vs. decision
   quality).
2. Roster tab's "Week by week" row headers reworked to match/complement its own
   drilldown: added a Worst-lineup column, renamed Top starter → Best starter,
   removed a duplicate-of-the-row fact card.
3. Added position + season-to-date position rank next to players in the
   "Best combined roster" drilldown table; split the manager out into its own
   column.
4. Added Worst lineup next to Best lineup in the row; changed "Best benched" →
   "Best bench" wording.
5. Added player portraits/manager portraits throughout the Week-by-week section
   (row + drilldown).
6. Added a "Managers this week" scoreboard beside Best combined roster (side by
   side, matching the Weekly tab's lineup-comparison layout); added a new
   "Season roster/player honors" cumulative section (times as best starter,
   best bench, best lineup, best-combined-roster picks).
7. Removed the now-duplicate drilldown facts (Best starter/Best bench) once the
   row itself carried the same info with portraits.
8. Added player portraits + PPG + fixed a real sorting bug in "Rosters by
   manager": a `{% if p.bench_pts %}` falsy-check rendered "—" for exactly
   0.0, which broke the sortable-table JS's "every cell has a number" check
   and silently downgraded that whole column to alphabetical string sort.
9. Reviewed the whole Roster tab for reading order/conciseness; found a column-
   order mismatch between sections, a naming inconsistency ("Season" prefix),
   and merged the two honors tables into one toggled "By manager / By
   position" section (`.viewswitch`, same idiom as the Draft tab).
10. Added win/loss colour + running record to "Managers this week"; grouped
    "Roster honors"' per-manager drilldown from a flat 26-row week log into an
    11-row (honor, player) summary with counts and week lists.
11. Renamed "Best combined roster" → "Players of the Week" throughout (code
    and display): `_best_combined()`→`_players_of_week()`,
    `week_best_combined()`→`week_players_of_week()`, `combined_picks`/
    `combined_weeks`→`potw_picks`/`potw_weeks`, template partial renamed
    `_best_combined.html`→`_players_of_week.html`. Added a star marker for
    POTW picks who were actually benched by their real team.
12. Suggestions for reorganizing charts to sit beside the table they actually
    depict instead of one block up top — implemented (opener stays
    league-wide; roster/heatmap/starter-bench charts move to "Rosters by
    manager"; boom_bust/consistency move to "Week by week").
13. Reordered the main tab nav (Transactions before Roster); asked for a
    resummary of the Coaching/Roster conceptual split to prep for
    reconciliation (found one real gap: two differently-computed "bench"
    concepts across the two tabs).
14. Reversed course from item 1: explicitly asked to merge Coaching into
    Roster as one "Management" tab, since efficiency was the only real
    differentiator. Backed up both templates first
    (`tab_roster.html.pre-merge.bak` / `tab_coaching.html.pre-merge.bak`,
    untracked, not committed), then merged.
15. Fixed a cosmetic `/favicon.ico` 404 by adding a real SVG favicon +
    `<link rel="icon">` on all three standalone pages (deliberately not on the
    self-contained season-report HTML, which stays zero-external-asset).

  `player_honors()` / `player_honors_by_position()` (grouped summaries, not

  `coaching`/`roster` branches merged into one, joining `coaching_detail()`'s

- `favicon.svg` added; linked from `index.html`/`home.html`/
  `weekly_report.html`.
